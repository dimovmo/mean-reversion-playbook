# Mean Reversion — сайт плейбука

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статический сайт в dist/
```

Деплой: Cloudflare Pages или Vercel, build command `npm run build`, output `dist`.

## Как добавить пример
1. Положите три скрина в `public/examples/` (WebP, одинаковая обрезка).
2. Скопируйте любой файл из `src/content/examples/`, поменяйте frontmatter и пути к картинкам.
3. Напишите разбор под frontmatter.

## Как добавить пример к термину глоссария
Кнопка «Подробнее» открывает окно со скринами и расширенным описанием термина.

- **Скрины:** положите их в папку `public/glossary/<id>/`, где `<id>` — поле `id` термина в `src/data/glossary.json` (например, `public/glossary/DR/1.webp`, `2.webp`). Порядок — по именам файлов. Если скринов больше одного, появятся стрелки (а также ← / → и свайп). Без скринов показывается заглушка.
- **Текст:** добавьте термину поле `"more": ["Первый абзац.", "Второй абзац."]`. Если поля нет, в окне показывается краткое определение.
