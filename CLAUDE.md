# Проект: сайт-плейбук Mean Reversion
- Astro + MDX. Контент в `src/content`, интерфейс на русском.
- Дизайн: тёмная тема по умолчанию (переключатель светлой), токены только из `src/styles/global.css`.
- Цвета: акцент #d97757, лонг #6fa383, шорт #c8695f. Без ярких неоновых цветов.
- Альтернативный стиль «Киберпанк» (`src/styles/style-cyber.css`, `data-style="cyber"`, кнопка-очки в шапке, `?style=cyber`). Ограничения по цветам выше к нему не относятся (неон допустим), базовый стиль остаётся по умолчанию. Новые компоненты должны выглядеть нормально в обоих стилях.
- Референс дизайна: `reference/prototype.html` (первый утверждённый прототип).
- Новый пример = новый `.md` в `src/content/examples` + три скрина в `public/examples/` (контекст, вход, результат).
- Термины глоссария: один `.md` на термин в `src/content/glossary` (имя файла = id; `d` — подсказка, тело — «Подробнее»; скрины — список `images` с `label`, как в примерах, файлы в `public/glossary/` (`snr-1.png`)), в MDX `<Term t="IDM" />`.
- Текст плейбука без запроса не переписывать.
- Графики для скринов не берём из TradingView, а генерируем: `node scripts/charts/render.mjs <имя>` по данным `scripts/charts/<имя>.json` (свечи OHLC, уровни, диапазон) → `public/glossary/<имя>.png` + `<имя>-light.png`. Эталон — `snr-1`. Стиль: только свечи, уровень и смысловая разметка (zones/ellipses/marks: FVG, HTV, Test), без сетки, осей, цен, дат и подписей TradingView; уровень — одна сплошная линия (2px в файле); фон = фон окна «Подробнее» (`.gm-sl`: тёмная #111, светлая #ececec, нейтральный серый одинаково для всех стилей). Стиль меняем в `render.mjs`, а не в отдельных картинках.
- Светлая версия скрина — файл рядом с суффиксом `-light` (`snr-1-light.png`), подхватывается автоматически (`lightOf` в `src/content.config.ts`).
